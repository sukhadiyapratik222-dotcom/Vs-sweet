# Vardayini Sweet Mart

Handmade mithai shop for Vadodara and Ahmedabad — catalog, cart, checkout, wishlist, stores, and admin.

## Clone this repo in VS Code

### Option A — VS Code command palette

1. Open VS Code.
2. Press `Ctrl+Shift+P` (Windows/Linux) or `Cmd+Shift+P` (Mac).
3. Run **Git: Clone**.
4. Paste:

```
https://github.com/sukhadiyapratik222-dotcom/vardayini-sweet-mart.git
```

5. Choose a folder, then **Open** the cloned project.

### Option B — terminal

```bash
git clone https://github.com/sukhadiyapratik222-dotcom/vardayini-sweet-mart.git
code vardayini-sweet-mart
```

`code .` also works if you already opened the folder.

### GitHub CLI

```bash
gh repo clone sukhadiyapratik222-dotcom/vardayini-sweet-mart
code vardayini-sweet-mart
```

If `code` is not recognized, in VS Code open the command palette and run **Shell Command: Install 'code' command in PATH**.
